Methodology

How It Works

A systematic 4-step pipeline bridging computer vision and deep learning inference.

1

1. Upload Skin Image

User uploads a dermatological photo (JPG, JPEG, PNG, WEBP) through the secure drag-and-drop interface.

2

2. Image Preprocessing

OpenCV decodes the image, performs RGB conversion, resizes to standard 224×224 resolution, and normalizes pixel intensities.

3

3. AI/CNN Model Analysis

The deep learning convolutional model computes spatial feature representations through convolutional layers and activation maps.

4

4. Preliminary Prediction

Softmax probabilities are classified into disease categories with confidence scores, risk levels, and clear clinical guidance.

Capabilities

Key System Features

Engineered for speed, transparency, and clinical responsibility.

Strict Non-Fake Model Protocol

The backend requires genuine TensorFlow weights. If the model file is not connected, the UI shows an honest disconnected state rather than faking diagnosis.

Confidence Visualizer

Displays exact probabilistic confidence percentages and full 7-class distribution breakdowns for complete classification transparency.

Low-Confidence Alerts

Predictions below 60% confidence are automatically flagged with an advisory recommending direct inspection by a certified dermatologist.

Prediction History & Logs

Built-in SQLite database stores past screening records with timestamped thumbnails and enables single-click record deletion.

Live Admin Diagnostics

Includes a dedicated status dashboard displaying model architecture, loaded class mappings, and API latency measurements.

Flexible Architecture

Plug-and-play support for MobileNetV2, ResNet50, EfficientNet, or custom CNN weights saved as model.keras or model.h5.

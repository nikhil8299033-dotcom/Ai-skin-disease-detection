AI-Based Skin Disease Detection

Comprehensive project documentation covering problem formulation, deep convolutional neural networks, transfer learning, and dataset benchmarks.

1. Problem Statement & Proposed Solution

Problem Statement: Skin diseases are among the most prevalent human illnesses globally, affecting over 1.9 billion people at any given time. Early detection of malignant skin lesions such as Melanoma is critical for favorable patient survival rates. However, access to board-certified dermatologists is often limited in remote or underserved areas, leading to delayed clinical evaluations.

Proposed Solution: This project proposes an automated, non-invasive preliminary screening web application powered by Computer Vision and Deep Learning. By enabling patients and general practitioners to upload dermatoscopic images, the system provides rapid classification probabilities across 7 major skin lesion categories, triaging cases that urgently require specialized dermatological examination.

2. Project Objectives

  • Implement an automated pipeline using OpenCV for lesion image ingestion, color-space conversion (BGR to RGB), spatial resizing to 224×224 pixels, and tensor normalization.
  • Leverage Convolutional Neural Networks (CNNs) and Transfer Learning backbones (MobileNetV2, ResNet50, EfficientNet) trained on verified dermatological datasets.
  • Construct an asynchronous, decoupled Flask REST API and SQLite persistence layer for rapid inference and audit logging.
  • Enforce strict ethical and clinical safeguards: clearly declaring preliminary screening status, highlighting low confidence (<60%), and refusing prescription generation.

3. Methodology, CNNs & Transfer Learning

Convolutional Neural Networks (CNN): CNNs are specialized deep learning architectures designed to process pixel matrices through spatial convolution filters. They automatically extract hierarchical features—ranging from low-level edges, textures, and color variations to high-level lesion border asymmetry and pigment networks.

Transfer Learning: Rather than training a deep network from scratch (which requires millions of medical images), transfer learning utilizes pre-trained base architectures (such as MobileNetV2, ResNet50, or VGG16) initialized with ImageNet weights. The feature extraction layers are frozen, and custom dense classification heads with Dropout and Softmax activations are fine-tuned on specialized dermatological data.

Mathematical Softmax Classification:

P(Y = j | X) = exp(z_j) / ∑ [exp(z_k)] (for k = 1 to 7 classes)

Converts the raw logit outputs from the top dense layer into a normalized probability distribution across all 7 disease categories.

4. Dataset Sources & Diagnostic Classes

The model is aligned with the benchmark HAM10000 ("Human Against Machine with 10,000 training images") dataset and the ISIC Archive (International Skin Imaging Collaboration):

1. MEL: Melanoma (Malignant)
2. NV: Melanocytic Nevus (Mole)
3. BCC: Basal Cell Carcinoma
4. AKIEC: Actinic Keratoses
5. BKL: Benign Keratosis
6. DF: Dermatofibroma
7. VASC: Vascular Lesions

5. Limitations & Future Scope

Current Limitations:

  • Image artifacts, hair, poor lighting, or camera defocus can degrade classification confidence.
  • Dataset class imbalance: Common moles (NV) significantly outnumber rare vascular or amelanotic lesions in standard datasets.
  • Lack of patient clinical history integration (e.g. age, genetic predisposition, anatomical lesion site).

Future Scope:

  • Integration of Grad-CAM (Gradient-weighted Class Activation Mapping) to visually highlight the salient heatmaps guiding model decisions.
  • Multimodal classification combining dermatoscopic images with patient metadata (age, sex, lesion localization).
  • Deployment as a mobile PWA (Progressive Web App) with on-device TensorFlow Lite / ONNX Web Runtime for offline edge inference.
